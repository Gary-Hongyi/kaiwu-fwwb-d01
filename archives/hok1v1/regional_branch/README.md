# 复赛同源迭代分支

此目录复制自原工作目录的“区域赛提交版”中的 `agent_ppo/`、`agent_diy/` 和 `conf/`，保留源码与配置，排除缓存、权重及重复的 V2 检查脚本。

项目作者确认，此分支与最终提交源码源于复赛某次共同迭代，最终选择的是 `代码.zip` 中的另一分支。由于共同节点和中间代码缺失，不还原具体分支时间。

与最终提交版相比：

- 少了拉扯攻击、残血回撤和兵线掩护三项奖励。
- 默认预加载编号 276912 的模型，评估配置指向编号 292449。
- 部分监控标签和注释不同。
- 原目录缺少根 `train_test.py` 和代码根 `kaiwu.json`，此次没有从其他版本借文件补成一个新版本。

本分支附带的 292449 权重保存在原始本地目录，没有随仓库提交。源码中的加载路径按原样保存，因此本目录不能作为开箱即用的独立训练包。
